# 📊 인문사회대 생활습관 및 만족도 분석 대시보드

인문사회대 학생회에서 학우들의 일상 생활습관(공부시간, 수면시간, 스마트폰 사용시간 등)과 학교생활 만족도 간의 관계를 파악하고, 한 줄 의견 텍스트를 분석하기 위해 개발된 Streamlit 기반 인터랙티브 데이터 분석 웹 대시보드입니다.

---

## 📌 주요 기능

1. **데이터 업로드 및 결측치/이상치 검증**
   - 사용자 정의 CSV 파일 업로드
   - 원본 데이터 테이블 미리보기 제공
   - 숫자 변환 오류 및 결측치 자동 필터링 및 제외 건수 통계 제공

2. **학과별 맞춤 필터링**
   - 특정 학과 또는 전체 학생 대상 필터 선택 가능
   - 선택된 학과에 맞춘 평균 학교생활 만족도(10점 만점) 자동 연산

3. **생활습관 및 만족도 시각화**
   - **산점도(Scatter Plot)**: 공부시간과 학교생활 만족도 간의 상관관계 시각화 (학년별 색상 구분)
   - **히트맵(Heatmap)**: 통학시간, 공부시간, 스마트폰 사용시간, 수면시간, 만족도 등 수치 변수 간 상관계수 표시

4. **한 줄 의견 텍스트 마이닝**
   - **워드클라우드(Word Cloud)**: 학우들이 남긴 한 줄 의견의 핵심 키워드 시각화
   - **빈도수 상위 10개 단어(Top 10)**: 가장 많이 언급된 단어 랭킹 막대그래프
   - **감성 단어 분석**: 긍정 및 부정 키워드 사전 기반 등장 횟수 집계 및 비교 그래프

## 🛠 실행 환경 및 설치

### 1. 가상환경 구성 (권장)
```bash
python -m venv venv
# Windows
source venv/Scripts/activate
# Mac / Linux
source venv/bin/activate
```

### 2. 필수 라이브러리 설치
```bash
pip install -r requirements.txt
```

---

## 🚀 대시보드 실행

터미널에서 아래 명령어를 실행하여 웹 브라우저에서 대시보드를 엽니다.

```bash
streamlit run app.py
```

실행 후 웹 화면에서 설문조사 결과가 담긴 `campus_life.csv` 파일을 업로드하면 즉시 분석 결과가 표시됩니다.

---

## 📂 데이터 포맷 안내 (CSV 파일 컬럼 예시)

대시보드 구동을 위한 CSV 파일은 다음 컬럼들을 권장합니다:

- `학과`: 학우 소속 학과명 (문자열)
- `학년`: 학년 (숫자/문자열)
- `통학시간`: 하루 평균 통학시간 (숫자)
- `공부시간`: 하루 평균 공부시간 (숫자)
- `스마트폰`: 하루 평균 스마트폰 사용시간 (숫자)
- `수면시간`: 하루 평균 수면시간 (숫자)
- `만족도`: 학교생활 만족도 점수 (숫자, 예: 1~10)
- `한줄의견`: 캠퍼스 생활에 대한 한 줄 의견 (문자열)
